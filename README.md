# Premier Design — сайт студии

Дизайн интерьера и мебель на заказ в Астане (Instagram @premier_design_studio).
Чистые HTML, CSS и JS, без сборки и внешних зависимостей.

## Файлы
- `index.html` — главная: первый экран, о студии, избранные модели, проекты, материалы, условия
- `catalog.html` — каталог с фильтрами и окном товара (кнопка заказа открывает WhatsApp с названием модели)
- `services.html` — услуги, процесс работы в 5 шагов, условия
- `contacts.html` — адрес, телефон, WhatsApp, Instagram, форма (открывает WhatsApp)
- `css/style.css` — оформление и анимации
- `js/main.js` — язык RU/KZ, каталог, меню, анимации
- `assets/img` — фото (у каждого фото мебели есть уменьшенная копия с `-s` в имени), `assets/fonts` — шрифты Cormorant и Onest

## Как править
- Товары: список `PRODUCTS` в начале `js/main.js` (категория, имя файла фото, название и описание на двух языках).
- Русские тексты страниц лежат в HTML, казахские — в списке `KZ` в `js/main.js` (ключ совпадает с `data-i18n`).

## Как выложить на GitHub Pages
Загрузить содержимое папки в репозиторий, затем Settings → Pages → Deploy from a branch → `main`, `/ (root)`.
